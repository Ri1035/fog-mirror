# 雾镜 · Fog Mirror

对着起雾的镜子，用手指或鼠标写下想说的话。摄像头实时画面作为镜底，上方覆盖可擦除的动态雾层。

单文件主体（`index.html`），**除手势/面部识别所需的 MediaPipe 外无任何框架**，UI 资源全部内联。

手势与呼气识别复用开源项目 [MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe)（Apache-2.0）：
`HandLandmarker` 做 21 点手部关键点，`FaceLandmarker` 读 52 组面部表情系数判断「呼气」。模型与 WASM 已随仓库离线内置在 `vendor/mediapipe/`。

---

## 一、运行

### 1. 本地运行（推荐）

```bash
cd /workspace
python3 -m http.server 8080
# 打开 http://localhost:8080/index.html
```

`localhost` / `127.0.0.1` 属于浏览器的「安全上下文」，无需 HTTPS 即可调用摄像头。**手势/面部识别也必须在 `http(s)://` 下运行**——直接双击打开（`file://`）时本地 `vendor/` 里的 `.mjs` 会被 CORS 拦下，此时程序会自动回退到 CDN 拉取模型（需要联网）。

### 2. 部署到线上

摄像头 API 要求 **HTTPS**。直接把整个目录（含 `index.html` 与 `vendor/`）放到任意支持 HTTPS 的静态托管即可（GitHub Pages / Cloudflare Pages / Vercel / Netlify）。

### 3. 没有摄像头也能看

未授权摄像头、无摄像头设备、或非 HTTPS 环境下，程序会**自动切到演示模式**（程序化流动色斑背景）并在顶部给出原因提示，所有交互仍可完整体验。

## 二、操作

鼠标与触摸行为一致。

| 操作 | 效果 |
| --- | --- |
| 单指 / 鼠标拖动 | 擦除雾层，露出下方镜中画面（笔刷带羽化软边） |
| 底部滑块 | 调节笔刷粗细（12–130） |
| 雾效模式 | `静态雾` 均匀半透明毛玻璃；`动态雾` 云絮随指针惯性流动 |
| `手写` 工具 | 拖动留下毛笔感墨迹（速度越快笔画越细），叠在雾上 |
| `图形` | 一键落笔：心形 / 星星 / 问号 / 笑脸，位置跟随光标 |
| `文字` | 输入文字后「落下」，以衬线艺术字 + 冷调渐变 + 辉光印在雾上 |
| 清除 | 雾面在 760ms 内**从四周缓缓覆回**，同时抹掉所有墨迹 |
| 保存 | 合成「镜面 + 雾 + 墨迹」导出 JPG |

控制栏无操作 2.6–7.6 秒后自动隐去，移动鼠标或触摸即重现。

### 键盘快捷键

| 键 | 功能 |
| --- | --- |
| `C` | 清除雾面 |
| `S` | 保存当前画面 |
| `H` | 收起 / 展开控制栏 |
| `1` / `2` | 静态雾 / 动态雾 |
| `[` / `]` | 笔刷变细 / 变粗 |
| `Esc` | 关闭图形弹层与文字输入 |

### 手势擦除 & 呼气喘气（真实识别）

点底部 `手势` 按钮开启，会同时申请摄像头与麦克风权限。开启后顶部出现状态条，实时显示两条识别链路的状态。

| 动作 | 识别方式 | 效果 |
| --- | --- | --- |
| 手伸到镜头前，食指移动 | MediaPipe `HandLandmarker` 取指尖（第 8 号关键点）→ 镜像映射 → One Euro 滤波 | 指尖划过处雾气被擦掉，留下清晰玻璃 |
| 对着镜头呼气 | `FaceLandmarker` 读 `cheekPuff` / `mouthPucker` / `mouthFunnel` 系数 | 雾气在玻璃上重新凝结漫回 |
| 对着麦克风吹气 | `AnalyserNode` 检测宽带气流噪声（RMS 能量 + 频谱平坦度，底噪自适应） | 同上，作为面部识别的兜底 |

- **双通道融合**：面部表情与麦克风气流任一命中即判定「正在呼气」，带 110ms 起判 / 700ms 保持的迟滞，避免抖动误触发。
- **自动降级**：无 WebGL、模型加载失败或推理连续报错时，手势回退到内置肤色指尖追踪，呼气回退到纯麦克风判定，功能不中断。
- **麦克风被拒**：不影响手势擦除，呼气只走面部表情通道。

## 三、实现原理

三层 canvas 叠加，其中雾与墨迹共用一个透明度蒙版：

```
#cam (video, 清晰原始画面, CSS scaleX(-1) 镜像)
  └─ #fogCanvas  ← 降采样模糊的镜底 + 白雾（被实拍浓淡图裁出厚薄）+ 颗粒，最后被 mask 裁切，再叠加 ink
       └─ #fxCanvas  ← 雾气消散粒子
```

| 离屏画布 | 作用 |
| --- | --- |
| `mask` | 记录「哪里有雾」。初始全白；擦除时用 `destination-out` 按软边印章打孔 |
| `ink` | 记录墨迹（手写 / 图形 / 文字），擦除时与 `mask` 同时被擦，实现「字随雾走」 |
| `fogReal` | `assets/fog-real.webp` 实拍冷凝雾 → 灰度浓淡图（离线已削掉水滴、抬升窗外景物、只留竖向流痕），坐标固定、不随时间平移 |
| `blurA` / `blurB` | 雾底的模糊链：视频先降到 1/8 分辨率，再经 1/3 中继升采样回全屏，两次双线性放大的叠加等效柔和毛玻璃，避开全屏 `backdrop-filter` 的性能开销 |

每帧合成顺序：模糊镜底 → 白雾径向渐变（中心均匀、边缘加厚）→ 冷调 → `destination-in(fogReal)` 裁出真实浓淡 → 细颗粒 → `destination-in(mask)` 裁出有雾区域 → `source-over(ink)` 盖上墨迹。全程约 8 次绘制调用。

> **雾为什么不自己动**：静态雾的组成里没有任何随时间变化的项 —— 实拍浓淡图按固定矩形绘制，颗粒图案不做 `setTransform` 平移，流速场（`updateFlow`）仅在「动态雾」模式下调用。实测同一场景连续 2.5 秒，雾层像素差值为 0.0000。

### 性能设计

- 渲染分辨率 = 显示尺寸 × min(DPR, 2)，硬上限 1800px；连续 90 帧均帧耗时 > 26ms 则自动降级到 0.6 倍（只降不升，避免画质抖动）。
- 笔刷用**预渲染软边印章** `drawImage` 平铺，每段不新建渐变对象。
- 粒子为**定长对象池**（140 个），运行时零分配。
- 噪声 / 云絮瓦片、`Path2D` 图形路径均只构建一次并复用。
- 页面隐藏时 `cancelAnimationFrame` 彻底停帧；窗口 resize 防抖 180ms。
- 关于内存：`URL.revokeObjectURL` 在 4 秒后释放；resize 时保留擦除与墨迹而非重建。

## 四、与原始需求的差异说明

1. **「手写文字自动识别」改为「手写美化成字」**
   真正的 OCR 必须引入 tesseract.js 之类的库，与「无需依赖外部库」冲突。当前实现走的是平滑插值 + 速度感变宽 + 三层描边（外发光 / 主体 / 高光芯）的毛笔质感渲染。
   如需接入 OCR，已预留钩子，无需改动画布逻辑：

   ```js
   // 手写笔迹的坐标点可直接交给任意 OCR 服务
   window.雾镜.recognize = async (points) => '识别结果';
   ```

   「转为艺术字体」的意图由 `文字` 工具完整实现（衬线体 + 冷调渐变 + 辉光）。

2. **「动态雾随鼠标移动产生流动动画」**：实现为带阻尼的惯性流场，指针推动云絮后自行衰减，比刚性跟随更接近真实雾气。

3. **雾底模糊**：未使用全屏 `backdrop-filter`（Safari 下不稳定且低端机掉帧），改用降采样 + 两段升采样等效实现，可在任意浏览器得到一致观感。

## 五、可继续优化的方向

**画面**
- 雾底改为「时间累积模糊」：静止区域的雾逐渐变浓，被扰动处变薄，更接近真实玻璃。
- 墨迹改用 `OffscreenCanvas` + Worker 处理长笔画的平滑与变宽，主线程零负担。

**交互**
- 手势从「指尖擦除」扩展到「捏合擦除、握拳清除」，彻底脱离控制栏。
- 呼气强度（而非仅布尔判定）映射到雾气凝结速度，喘气越重雾越厚。
- 笔画压力支持 `PointerEvent.pressure`，让数位板 / 支持压感的触屏写出真正的提按顿挫。
- 撤销 / 重做：把 `ink` 与 `mask` 的每步操作压入环形缓冲，记录增量而非整图快照。

**工程**
- 视频帧改用 `requestVideoFrameCallback` 驱动渲染，而不是固定 rAF，省掉重复绘制的同一帧。
- 把 `mask` 与 `ink` 换成 `OffscreenCanvas` 并在 Worker 中擦除，进一步降低主线程压力。
- 引入 WebGL 做雾的渲染（片元着色器里做噪声 + 模糊），可支撑 4K 分辨率与更复杂的体积雾。
- 导出改为 MediaRecorder 录制擦除过程，生成短视频。

**无障碍**
- 为纯键盘用户提供方向键 + 空格移动虚拟笔刷的路径。
- 遵循 `prefers-reduced-motion` 时默认静态雾并关闭粒子（当前已禁用 CSS 过渡，可再关掉粒子与云絮漂移）。
